## [1.0.0] - 2025-12-27

### Added
- Initial release of Shoe Store App
- Product browsing with grid and list views
- Shopping cart with quantity management
- Filter shoes by brand, size, and price range
- SQLite database for local storage
- Admin panel for inventory management
- Add, edit, and delete products
- Product detail screen with full information
- Material Design 3 UI
- Provider state management
- Persistent cart across app restarts
- Import/export database functionality
- Permission handling for file access
- Image caching for better performance
- Responsive layouts for different screen sizes

### Features
- **Product Management**
  - Browse shoes catalog
  - View detailed product information
  - Filter by multiple criteria
  - Search functionality

- **Shopping Cart**
  - Add items to cart
  - Update quantities
  - Remove items
  - Calculate total price
  - Persistent cart storage

- **Admin Panel**
  - Add new products
  - Edit existing products
  - Delete products
  - Manage inventory

- **Database**
  - SQLite local storage
  - CRUD operations
  - Database export/import
  - Sample data generator

### Technical Details
- Flutter 3.24.5
- Dart 3.5.4
- Provider state management
- SQLite database (sqflite)
- Material Design 3
- Cross-platform support (Android, iOS, Linux, Web, Windows)
